# Lucian Solutions
Lucian's personal website for image storage, blog posts, and services.

Set `PUBLIC_FILE_SERVER_URL` in the environment when starting the production server.
SvelteKit 3 reads this public variable at runtime for both pages and API routes.

| Pages       | Description                                     |
| ----------- | -----------                                     |
| **API**     | API services                                    |
| **Posts**   | Blog posts by Lucian                            |
| **Fanarts** | Fanarts made by the community & requested works |
